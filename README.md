# 🤖 Telegram Bot (tg_bot_V2)

Учебный проект Telegram-бота, разработанный на Python. Бот обрабатывает команды пользователей и выполняет различные действия в зависимости от логики.

## 🚀 Функционал

- Обработка команд (/start, /help и др.)
- Ответы на сообщения пользователей
- Работа с API (если есть — уточни)
- Логика взаимодействия с пользователем

## 🛠️ Технологии

- Python
- aiogram (или что ты использовал)
- Telegram Bot API
